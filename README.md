Voici notre programme du codename duo !

En voici le sénario:

Les deux joueurs voient la même grille de 25 mots,
chacun a sa propre clé secrète indiquant quels mots il doit faire deviner.
À ton tour de donner un indice:
clique sur « Voir ma clé » pendant que ton partenaire détourne les yeux,
choisis un seul mot pour l'aider à trouver tes agents.
L'autre joueur clique sur les mots qu'il pense corrects : attention aux assassins !
Ensuite, échangez les rôles et continuez jusqu'à avoir trouvé tous les agents 
avant la fin du nombre de tours imposés.
Le tour se termine lorsque une erreur est commise et la partie est perdue si l'assassin est choisi.
